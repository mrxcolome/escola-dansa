# formación escénica

el entrenamiento completo del artista: jazz, contemporáneo, hip-hop y danza del vientre, todo en una misma tarde de viernes. para quien quiere el escenario de verdad.

## para quién

para jóvenes que quieren una formación artística completa: bailar varios estilos y hacerlo en el escenario. la mejor preparación para musicales, castings y escenarios — o simplemente para disfrutarlo todo.

## beneficios

- **formación 360°**: cuatro disciplinas en una tarde: la polivalencia que pide el escenario actual.
- **todo en uno**: una sola formación para probarlo todo y descubrir dónde brillas más.
- **espíritu de compañía**: el grupo funciona como una pequeña compañía: piña, proyecto y escenario.
